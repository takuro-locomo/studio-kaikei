# studio-kaikei

スタジオ（撮影／レンタル／レッスン等）の会計をシンプルに回すための Web アプリ。
レシート・請求書を撮って送るだけ、しゃべるだけで、売上と経費が帳簿になる状態を目指す。

## やりたいこと

1. 領収書・請求書をスマホから写真／PDF でアップロードして保存する
2. 「今日のレッスン料 8000円、現金」のように音声で話すだけで売上・経費を記録する
3. 記録は月次で集計し、勘定科目ごとの内訳を見られるようにする
4. 確定申告・税理士提出用に CSV（freee / マネーフォワード形式）で書き出す

## 想定する使い方

- 現場で支払ったらその場でレシートを撮影 → 自動で日付・金額・支払先を読み取り、確認して保存
- 1日の終わりに音声で売上をまとめて入力
- 月末に一覧を確認し、未入力・要確認のものだけ手で直して CSV 出力

## 機能要件（MVP）

### 取引の記録
- 収入／支出の区分
- 日付、金額、税区分（10% / 8% / 非課税）、勘定科目、取引先、メモ
- 入力方法：音声入力、手入力、レシート画像からの自動抽出

### 音声入力
- ブラウザのマイクから録音し、テキスト化
- テキストから日付・金額・科目・支払方法を推定してフォームに反映
- 保存前に必ず確認画面を挟む（誤認識をそのまま帳簿に入れない）

### ファイル管理
- 画像（JPEG/PNG/HEIC）と PDF に対応
- 取引レコードと証憑ファイルを1対多で紐づけ
- 電子帳簿保存法を意識して、日付・金額・取引先で検索できるようにする

### 集計・出力
- 月次／年次の収支サマリ
- 勘定科目別の内訳
- CSV エクスポート

## 勘定科目（初期セット・スタジオ向け）

収入: 売上高（レッスン料 / レンタル料 / 撮影料 / 物販）
支出: 地代家賃、水道光熱費、通信費、消耗品費、広告宣伝費、支払手数料、旅費交通費、外注費、減価償却費、雑費

## 技術構成（案）

| レイヤ | 候補 |
| --- | --- |
| フロント | Next.js (App Router) + TypeScript + Tailwind CSS |
| PWA | スマホのホーム画面から起動、カメラ・マイク利用 |
| 認証・DB・ストレージ | Supabase (Auth / Postgres / Storage) |
| 音声認識 | Web Speech API（無料・簡易）もしくは Whisper API（高精度） |
| レシート読み取り | OCR + LLM で日付・金額・取引先を構造化 |
| ホスティング | Vercel |

## データモデル（案）

- users … 利用者
- transactions … 取引（date, type, amount, tax_rate, account, partner, payment_method, memo, source）
- receipts … 証憑ファイル（storage_path, ocr_text, transaction_id）
- accounts … 勘定科目マスタ

## 開発ステップ

1. リポジトリ初期化・Next.js 雛形
2. 取引の手入力 CRUD と一覧・月次集計
3. レシート画像アップロードと保存
4. 音声入力（Web Speech API）→ 確認 → 保存
5. OCR による自動読み取り
6. CSV エクスポート
7. PWA 化・認証・複数ユーザー対応

## 注意事項

- 本アプリは記帳を補助するもので、税務判断は税理士に確認すること
- 証憑の保存要件（電子帳簿保存法）は運用開始前に最新の要件を確認すること
